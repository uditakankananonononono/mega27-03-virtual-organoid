Exact CellProfiler combined CSV: https://raw.githubusercontent.com/hmbotelho/FIS_analysis/master/demo_dataset/05-images_analysis/demoplate_01--cellprofiler--analysis/FIS_rawdata.csv , downloaded SHA256 `1cb65d37fe78ad232c9829634c4ed7be8afc52e9e0308a519673eb3a9d91f807`. Well descriptor: https://raw.githubusercontent.com/hmbotelho/FIS_analysis/master/demo_dataset/02-microscope_infile/demoplate_01.txt , SHA256 `70195928bdca463f287451bb3f056203a355893d8a6c37713c166461298d13f8`. The provider's live recursive tree has 448 exported TIFFs, 448 CellProfiler mask PNGs, and 64 per-well object CSVs, consistent with README's one plate x 64 imaged wells x seven timepoints. The downloaded summary has 31,900 object rows in exactly 64 wells each with seven timepoints, 16 wells per `fsk`, `fsk_809`, `fsk_770`, `fsk_770_809`, and eight wells at each forskolin concentration 0.008/0.02/0.05/0.128/0.32/0.8/2/5 uM. No zero-forskolin or CFTR-inhibitor level is named in these 64 source wells. Note 0.008 uM is low but *not* zero.

**Track-ID contradiction:** the README says CellProfiler `TrackObjects` assigns unique numeric labels to organoids across time. But the actual combined CSV has 1,080 rows with missing `TrackObjects_Label_4`, and 929 nonmissing well x time x label groups with 2-3 object rows each (965 excess rows), for example well 1, time 2, label 2 has two objects. Each of 4,265 distinct within-well nonmissing labels appears at both time 0 and time 6, but this does not certify one-to-one trajectories when labels collide at one timepoint. Do not compute naive single-organoid paired swelling or use these labels as an independent phenotype test without a fixed resolution audit. This is a source-table conflict, not proof the author's biological results are wrong. A provider mask PNG was fetched and visually inspected: colored separated masks on black, 512 x 512, but these are algorithm-generated, not hand-drawn ground truth.

The README describes a homozygous class-II CFTR mutation but no independent donor IDs here. One fluorescence/calcein demonstration plate with VX-809/VX-770 differs from the original VO3 brightfield VX445/VX661/VX770 source and lacks control arms required for specificity. The released processed masks are useful for a separate workflow/robustness case study, not a fresh original benchmark or confirmation of the failed biological gates. This protocol is post-result; no independent cohort or causal claim is made. Complete counts and exact source hashes are in `results/postresult_external_fis_demo_source.json`, regenerated by `scripts/audit_postresult_external_fis_demo_source.py` after downloading the pinned files.
