# VO3 attrition wording correction

27 September 2026. The title and abstract phrase “missing-data-robust” and a primary question phrased “after accounting for track attrition” imply that the donor-level swelling contrast is identified after missing A1 correction. It is not. The original response analysis selects positive A1 pairs; the source table has 6,964 baseline-detected organoids in original eligible blocks and size cells, of which 4,964 have positive A1 (2,000 do not). `results/missing_endpoint_bounds.json` shows an adverse/favorable response envelope crossing zero. `results/crossfit_inclusion_sensitivity.json` weights derived inclusion among positive-area pairs only, so it cannot impute or identify the 2,000 unobserved endpoints or baseline-undetected objects. The original sign-only and zero-forskolin gates remain failed. Amend title/abstract/primary question from robustness or correction language to a size association alongside a structured attrition audit; state that the full baseline-detected population effect remains unidentified. This is precision in presentation after results, not a gate change.
