# Frozen human-organoid mask model on mouse-intestinal YOLO boxes: external-domain negative

Source: https://zenodo.org/records/6768583 (Domènech-Moreno et al.; mouse intestinal organoids, EVOS 4x, four morphology classes). The 193,854,481-byte public ZIP matches the published MD5 `98f10253594f37fdee809dd61d618861`. It contains 756 released train and 84 released validation JPEGs, each paired with a YOLO annotation TXT. No literal image SHA256 repeats across target train/validation or the original OrgaSegment Basic images. A 32x32 standardized-thumbnail cosine screen flags 16 train/validation pairs at >=.95 and one target-validation/original-training candidate at .95196, but manual review of the latter (target Image256 vs original 20210727_31734) showed distinct layouts. A target train/val high-score example Image93 vs Image113 shows similar whole-field lighting and may capture a related field; there is no acquisition metadata to rule it out. We do not claim the released split is scene-independent. The frozen model was trained on the OTHER dataset, so target train/val similarities do not by themselves contaminate model training.

As fixed in `notes/postresult_mouse_yolo_domain_protocol.md` before target score inspection, run the already frozen OrgaSegment-trained U-Net v2 weights and its fixed human-validation postprocessing, with no mouse retraining or parameter selection. Convert predicted instances to tight boxes. Collapse the target's four morphology classes into one object class. Match boxes one-to-one at IoU >=0.5. On all 84 target validation images, aggregate TP=850, FP=911, FN=1618 across 2,468 valid target boxes: micro precision 0.482680, recall 0.344408, F1 0.401986. Per-image F1 mean 0.340087. The released label for Image710 contains one zero-width box; it was retained in the anomaly ledger and excluded from the valid-box denominator (the remaining 33 annotations in that image were scored). All image/label SHA256s and per-image counts reside in `results/postresult_mouse_yolo_domain.json`, generated by `scripts/audit_mouse_yolo_domain.py`. The image sources for a low-scoring field Image158 and higher-scoring Image51 were visually inspected; they differ in object density and contrast, consistent with a severe domain shift, not enough to diagnose cause.

This negative measures class-agnostic *bounding-box detection* in a mouse dataset, not AP50 for human organoid **instance masks**. Its 0.402 F1 cannot be compared numerically with the published 0.76 mask AP50; published baseline predictions on these 84 target images are unavailable, so no leading-tool comparison is claimed. Source field independence and label consistency need auditing. The check limits out-of-domain deployment of the current tool; it is not a discovery about CFTR response and cannot repair the failed original donor sign/specificity tests. New matched mouse training, a held-out scene-disjoint mouse test and a paired reference detector could test mouse generalization, but those would be a different project from the human CF segmentation benchmark.
