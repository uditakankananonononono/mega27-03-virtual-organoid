# VO3 round 06: repeated-field object-area and boundary consistency

Date 2026-09-26. A ChatGPT role-play critique of pasted paper text proposed 'annotation stability' by deterministically transforming an original mask. That proposed metric is tautological for intensity-only transforms: the annotation does not change because no new annotator relabels it. We reject it as a measure of human annotation uncertainty. Existing raw masks do permit a narrower, direct repeated-field comparison.

Post-result exploratory protocol: use three cross-split pairs fixed by the prior image-only graph's cosine >=0.99, before reading any model output here. They depict almost identical organoid layouts, but may be successive acquisitions, shifted tissue, or separately exported masks; annotator identities are unknown. For each pair at original 512x512 coordinates, match instance labels one-to-one with maximum IoU (Hungarian), keep matches IoU >=0.5, and report signed and absolute log area ratio, centroid displacement in pixels, and binary boundary F1 at a fixed one-pixel tolerance (boundary dilation). Also report exact foreground Dice already used, for context. Compare two distinct-layout negative-control pairs fixed in `results/scene_label_consistency.json`; do not force a match when none exists. A synthetic exact-copy control must return area drift 0, centroid displacement 0, boundary F1 1, validating the implementation.

A repeated field with high overlap yet meaningful area/boundary drift supports annotation/acquisition variability in this release, not independent human-rater disagreement or a universal AP50 ceiling. No model predictions or new holdout score may be used to select pairs, thresholds, or rewrite benchmark gates. Record every matched object and aggregate per-pair summaries; controls and null results stay visible. The missing donor-treatment raw masks remain unavailable, so this study cannot validate the CFTR size interaction biologically.
