# Frozen same-source masking benchmark for an attrition envelope, 28 September 2026

This is a method stress test on the **already observed** positive A0/A1 tracks of the original 31 donor x experiment x positive-forskolin-dose blocks; it does not reveal an independent cohort or make missing A1 in the real source identifiable. The original donor sign and zero-forskolin gates stay FAIL and the segmentation benchmark win remains withdrawn. No simulation results were computed before this protocol and script commit. Source: https://zenodo.org/records/10610438, `ResearchData/DIS_database.csv`; require pinned SHA256 `0e0e7913947a29c7b32ce87ca73a98614033d41ce63063a1d65053e766b2f315`. Use the source's t0 and t1 rows joined one-to-one by donor, experiment, well, condition, forskolin dose and particle; keep positive finite A0 and A1, DMSO or VX445_VX661_VX770, fixed A0<722 or >=1400 px, and the 31 block keys in `results/blocked_size.json`. The untouched *known* full-positive-pair response log(A1/A0) yields the simulation truth: block effect = treated-large minus DMSO-large minus treated-small plus DMSO-small, donor median across existing blocks, equal mean across 12 donors. Baseline-undetected and truly absent source endpoints are excluded; this is explicitly a synthetic missingness validation, not biological replication.

Generate 100 independent deterministic masks per mechanism using NumPy default_rng seeds 20260928..20261027, masking Bernoulli observations at the *individual object* level, with each original donor/block/cell retained at >=3 (redraw a cell's Bernoulli masks using a separately seeded generator at most 100 times; if still <3, mark replicate ineligible and report it, do not drop the cell). Three fixed mechanisms:

1. MCAR: missing probability 0.20 for every known track.
2. Baseline-observable MAR: missing probability `clip(expit(-1.5 + 0.45*I(small) + 0.35*I(treated) + 0.25*z(log1p(A0)) - 0.25*z(score0)), 0.05, 0.60)`, where z mean/SD is computed from all full known-positive tracks before masks, not from outcomes.
3. Outcome-dependent MNAR: MAR logit above plus `+0.8*z(log(A1/A0))`, using the full-known outcome only for **generating** missingness; estimators never receive it for masked tracks. This tests failure when long-track response itself drives missingness. The positive coefficient and all constants are fixed before masks.

For each masked replicate estimate four things on the remaining visible outcomes, using the same 31 blocks and donor aggregation:
- Complete case: point estimate of the donor-equal mean from visible tracks; no uncertainty claim.
- Baseline-only IPW: use `1/(1-p_MAR)` as known, clipped at 20, normalize within each block/arm/size. In MCAR `p_MAR=0.20`; in MNAR use the MAR expression without the hidden outcome term, deliberately misspecified. This is a favorable known-propensity reference in MCAR/MAR, not a deployable fitted estimator or a valid MNAR correction.
- Cell-specific envelope: for each treatment x size pool of retained outcomes across the 31 blocks, compute empirical 5th and 95th percentiles. Put missing outcomes at the lower bound in positive-sign contrast cells and upper bound in negative-sign cells; reverse for the upper endpoint. Preserve visible outcomes. Aggregate exactly as truth. The bounds are *hypothetical percentile scenarios*, not formal support bounds or confidence intervals.
- Global envelope: identical construction, but use one pooled 5th/95th percentile for all four arm/size cells. This is the simple comparator for interval width; it also has no coverage guarantee.

Report for every mechanism: number of eligible masks, missing fractions by cell, full-known truth, mean bias/MAE for complete case and IPW, empirical containment of truth and median/mean width for each envelope, proportion of runs each interval contains zero, and width ratio cell-specific/global. Do not optimize parameters or mask mechanism after results. A narrow methodological success requires cell-specific envelope >=90% empirical containment AND >=10% lower median width than global in *each* MCAR, MAR and MNAR; otherwise declare this locked criterion failed, including any tradeoff. Even a pass would show only synthetic-mask calibration on the observed-positive subpopulation in one accession, not verified real-missing A1 values, original biological gate, or global novelty. Report whether 5th/95th support fails directly by tallying how many hidden outcomes lie outside each selected bound. Do not compare interval coverage to point estimates as though they are confidence intervals.
