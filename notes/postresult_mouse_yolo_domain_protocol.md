# Distinct mouse-intestinal image-domain assay, designed after OrgaSegment eval exposure

Date 27 September 2026. The original OrgaSegment Basic 12-file AP50 outcomes, v1/v2 checkpoints and image-field overlap have already been seen. This is a fresh external-domain **object-detection** transfer check, not a repaired benchmark gate or a Mask R-CNN AP50 comparison. The target Zenodo 6768583 is mouse intestine at 4x EVOS, with hand-drawn YOLO *bounding boxes* and four morphology classes. It differs from human CF intestinal brightfield instance masks; the metric cannot be compared to mask AP50 0.76. Source: https://zenodo.org/records/6768583 and paper DOI 10.1242/dmm.049756.

Before viewing any target images or scoring outcomes, pin source ZIP MD5 `98f10253594f37fdee809dd61d618861` from the Zenodo file listing. Download the 193.9 MB ZIP, hash and enumerate its train/validation files without trusting folders as independent biological acquisition groups. Deduplicate image hashes and check high thumbnail similarity between the target train/validation partitions and with original OrgaSegment source. Choose the target's 84 validation images by original released split as the fixed evaluation set, not by target performance. Use the already frozen v2 U-Net `best_v2.pt` plus its fixed val-selected postprocessing `[.5,.5,.3,40]`; do not fine-tune or reselect any threshold on mouse images. Convert its segmentation instances to tight detection boxes at native target image dimensions using the same 512-pixel resizing and three-view inference. Score class-agnostic object recall, precision and F1 at box IoU >=0.5 via one-to-one matching, with per-image and aggregate micro counts. No model output determines image eligibility. YOLO boxes may include margin and omitting certain morphologies changes interpretation; record empty and ambiguous annotations. Report per-image values and source hashes. Bootstrap images only as descriptive uncertainty, not biological independence.

If target files turn out to be a different format or overlap with training data unexpectedly, stop and report the mismatch; do not silently remap or split. No benchmark-leading, clinical, patient-general or biological discovery claim follows from success. A negative helps limit the tool's deployment claim. Include a baseline or external published model only if paired predictions under the identical annotation/scorer can actually be obtained; otherwise explicitly say the cross-domain check lacks a leader comparison.
