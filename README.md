# Virtual organoid research toolkit (MEGA-PROGRAM-27, item 3)

Research code and a working paper of at least 20 pages on the OrgaSegment single-organoid CFTR-modulator swelling assay, U-Net image segmentation, and GEO organoid-to-GTEx tissue fidelity. The findings are exploratory: a stricter donor x plate x dose size-effect test failed (9/12 donor medians positive, p=0.073), a paired no-forskolin specificity check also failed (3/11, p=0.967), the U-Net does **not** beat the published segmentation benchmark, the proposed metabolic-parenchyma mechanism is unproven, and the apparent broad culture-fibroblast attractor was retracted after a sample-level audit. Do not use the fidelity rank or size-response estimates for diagnosis or care decisions.

## Reproduce and use

```bash
python3 -m pip install -e . --no-build-isolation  # or use a modern pip (>=23)
python3 -m pytest -q
vorganoid --help
```

The repository contains the real source data, reference tables, test fixtures, and trained U-Net checkpoint required for the examples. Large GEO profiles are generated by the research scripts and may be absent from a fresh clone; the single example below therefore uses a committed reference and the committed OrgaSegment table. For a reproducible fidelity example from a fresh clone, the included test constructs a small reference and profile. Do not mistake a precomputed `lcpm` profile for raw counts.

### Size-aware FIS effect from single-organoid data

```bash
vorganoid sizeaware data/raw/orgasegment/dis_merged_A0.csv \
  --drug VX445_VX661_VX770 --forskolin-col forskolin_concentration_µM
```

This estimates within-donor Trikafta-minus-DMSO log-swelling by pooled starting-size quartile, with at least five observations per donor x treatment x bin and donor-bootstrap CI. On the included data it yields 14 evaluable donors, mean large-minus-small attenuation 0.249 [0.165, 0.326]; three donors lack enough small organoids. The DMSO-controlled effect is an assay analysis, not a patient prediction.

### Fidelity score, requiring a matched expression source

```bash
# Raw gene-by-sample counts, Ensembl IDs in the first column:
vorganoid fidelity counts.csv --reference data/ref/gtex_v8_median_tpm.gct.gz \
  --organ-tissue Liver --purity data/ref/hpa_single_cell_type_v_api.tsv.gz
# A one-column precomputed log expression profile instead:
vorganoid fidelity profile.csv --profile --reference data/ref/gtex_v8_median_tpm.gct.gz \
  --organ-tissue Liver
```

Counts must be unnormalized nonnegative gene counts with library-scale columns (>100,000 reads per column); `--profile` is for precomputed log-expression, not a count matrix. GTEx v8 median TPM is a bulk-tissue reference, so differences in cell mixture, age, source tissue, protocol and platform can dominate a rank. HPA `--purity` restricts to genes enhanced only in parenchymal cell types. The output's `culture_attractor` merely says whether fibroblasts rank first; it is **not** a validated biological attractor.

### Image segmentation (research-grade)

```bash
vorganoid segment path/to/brightfield.jpg --model results/trainonly_seg/best.pt \
  --size 512 --selection results/trainonly_seg/val_selection.json \
  --tta-three --out labels.png
```

A later v2 checkpoint scored 0.761108 on those evaluation files, but a post-result audit found repeated acquisition fields crossing train, validation and evaluation filenames. We withdraw any claim that this is an independent benchmark win; the original arithmetic and split-overlap pairs are preserved in `results/trainonly_seg/sealed_eval_v2.json` and `results/seg_split_integrity_v2.json`. Group-disjoint retraining and a new independent test are needed.

The 16-bit output is a label image, not a pretty preview. Use an appropriate image viewer for instance labels; the prediction is not a diagnostic. The separately selected clean train-only checkpoint reached AP50 = 0.738672 with the original published scorer on the nominal OrgaSegment eval-file split, below the published mean 0.76; see `results/trainonly_seg/finding.md` and `results/trainonly_seg/sealed_eval.json`. This command uses the fixed validation-selected postprocessing and three-view prediction of the sealed benchmark; when --selection is given, the CLI requires --size 512 --tta-three rather than silently changing the validated inference protocol. The shipped checkpoint is a training-state dictionary, loaded in tensor-only mode. This is research-grade segmentation, not a clinical assay. The model may not generalize to other microscopes.

## Evidence, negatives and provenance

- `paper/mega27-03-virtual-organoid-paper.pdf`: working paper with embedded Times New Roman, equations and figures.
- `results/finding_size_dependent_swelling.md`, `results/finding_blocked_size.md`, and `results/finding_strict_organs.md`: positive, negative and inconclusive analyses.
- `results/external_fis_source_audit.md`: why examined public external datasets have not yet provided multi-donor single-object replication of the modulator-specific size finding.
- `results/datasets_ledger.csv`: accession-level source list. GEO and ArrayExpress entries count once per accession; the two single-cell runs of GSE108291 count once.
- `results/tools_ledger.csv`: tools actually used, with infrastructure excluded from the research-tool gate.
- `results/preregistration_*.md`: tests fixed before new data queries where possible, with deviations disclosed.

Primary assay source: Lefferts et al., OrgaSegment, https://www.nature.com/articles/s42003-024-05966-4 ; deposited data Zenodo https://zenodo.org/records/10610438 and https://zenodo.org/records/10278229 . See the paper's references for GTEx, GEO, HPA and ArrayExpress.

### Strict matched-block stress test (same discovery accession)

```bash
vorganoid matched-blocks data/raw/orgasegment/dis_merged_A0.csv \
  --drug VX445_VX661_VX770 --small-max 722 --large-min 1400
```

This is the donor x experiment x forskolin-dose contrast rather than the pooled-quartile `sizeaware` summary. It exactly reproduces the pre-registered negative in `results/blocked_size.json`: 31 eligible blocks, 12 donors, 9 positive medians, one-sided sign p=0.072998 and H1 **FAIL**. Both size cutoffs were originally chosen with this same dataset; the new command does not turn the negative into an external replication or support clinical use. Its machine-readable output includes each eligible block, cell counts, donor median and a warning.
