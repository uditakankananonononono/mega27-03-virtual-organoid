# Frozen 2021 iPSC intestinal FIS supplement suitability check

Source: https://www.mdpi.com/2073-4409/10/12/3419 , archived PMC full text https://www.ebi.ac.uk/europepmc/webservices/rest/PMC8699884/fullTextXML . The Methods explicitly track individual intestinal iPSC-organoid size over a 4-hour swelling assay, and Results name only CF1 as the CF line. Before inspecting any downloaded supplement, check its archive manifest, filenames and tabular schemas for raw object IDs, baseline and time-point sizes, condition (VX-809/VX-770 versus vehicle), and independently identifiable multiple CF donors. If one CF line only or summary figures only, do not treat it as multi-donor replication. No outcome analysis under this audit; preregister a separate exact test before reading substantive treatment results. The supplement's public presence is not enough to count a primary-used accession. No count added for metadata/suitability checks.
