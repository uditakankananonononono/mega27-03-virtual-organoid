# Benchmark integrity audit, registered before any new benchmark evaluation

Current training code at repo dba84f7 uses OrgaSegment `train + val` images. Post-processing in tune_seg.py was selected using the overlapping val images, creating a validation-set leakage; eval images were not used for training. The primary published comparator is eval mAP@0.5 0.76 +/-0.12 (Lefferts et al. 2024, https://www.nature.com/articles/s42003-024-05966-4). The current U-Net + TTA/post-processing eval is 0.73295 (results/seg_eval_tuned_512.json), below that.

Audit questions, fixed before running: (1) verify train/val/eval filenames do not overlap and the train/val union is the actual network-training set; (2) recompute eval mAP@0.5 from saved per-image scores, bootstrap the twelve eval-image scores (seed=0, 10,000 resamples) and report uncertainty for the difference to 0.76. This cannot verify metric implementation equivalence and does not substitute access to the published baseline's per-image predictions. (3) detect overly optimistic wording in paper/README, mark the val score invalid for selection claims. Do not retrain or tune against eval. A naive bootstrap probability of beating 0.76 is descriptive, not statistical superiority over a random baseline without the leader's paired per-image data. Keep the benchmark negative.
