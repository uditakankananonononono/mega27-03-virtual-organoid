# Train-only U-Net segmentation attempt, frozen before model fitting

This is the follow-up to `results/preregistration_benchmark_reproduction.md`. Data already in the repository: OrgaSegment Basic, Zenodo 10278229, with 184 `train`, 35 `val`, 12 untouched `eval` images. The earlier model wrongly used train+val for network fitting, so its validation-tuned score is biased. The aim is an honest new model, not a promised benchmark win.

Architecture and fixed training protocol: existing `src/vorganoid/seg.py` 3-class U-Net, 512 x 512 resized grayscale input, 256 x 256 random crops, batch 2, weighted pixel cross-entropy weights (1,1,3), Adam lr 0.002, random horizontal/vertical flips and 90-degree rotations, torch and NumPy seeds 2026. Train on `train` (184 images) **only** for up to 60 epochs. Preserve RNG/optimizer state at each epoch for resumed training. Score validation cross-entropy on the 35 disjoint `val` images every five epochs from epoch 5 through 60; save the minimum-loss checkpoint, ties favor earliest. No evaluation set image or metric is consulted during model selection. No adaptive hyperparameter tuning from eval. Any interruption that prevents completion is reported, not hidden. At the end choose postprocessing using val only from the *already written* grid in `tune_seg.py`: foreground [0.4,0.5,0.6], seed [0.5,0.6,0.7,0.8], boundary [0.2,0.3,0.5], minimum size [10,20,40] and three-view TTA. If the grid is too expensive, default `instances_from_probs` is acceptable only if selected before eval. One final evaluation on the 12 untouched images uses the author-release Cellpose-style AP and our AP with source-indexing caveat, prints every per-image score and uncertainty, and compares to published 0.76 +/- 0.12. A benchmark match/win needs a measured value at or above 0.76 **and** a credible plus-point that is not built from eval selection; even then, metric comparability and uncertainty must be disclosed. No diagnosis or patient treatment inference.
