# Pre-registration: IntAct PSIQUIC interaction-count contrast

Lock the first 20 rows by current rank (CSV order) for Liver and Brain - Cortex in `results/strict_organ_deficits.csv` before new service queries. Map each symbol to a unique reviewed-human UniProtKB accession using the previously downloaded GOA GAF; if none or multiple distinct accessions, mark missing. Query IntAct PSIQUIC `identifier:<accession>?format=count` for every uniquely mapped symbol. Counts are number of indexed interactions, not distinct biological partners, and may include nonhuman interactors. Primary H1 is liver < brain on per-gene `log1p(count)`, one-sided Mann-Whitney with p<0.05. Require >=15 measured genes in each group, else uninterpretable. Report all counts, accessions, errors, and medians. Follow service throttling: <=4 concurrent, one attempt per accession; errors are missing, not zero. This is a source-annotation comparison selected after prior analysis, not a direct measure of organoid interaction states or diagnosis. The 20 fixed top-ranked genes may include non-parenchymal blood/immune genes, so do not overinterpret.
