## Public matched-object assay

The earlier bounded source audit in `results/external_fis_source_audit.md` records distinct cohorts with suitable treatment biology but well-aggregate or request-only data, and public object examples with the wrong tissue/assay or no multi-donor identifiers. Examples: Drevinek et al. twenty-patient intestinal series (https://zenodo.org/records/4771466) has well-level area trajectories; Lefferts et al. (https://www.mdpi.com/1422-0067/24/19/14539) says data are available on request; Berical et al. (https://www.nature.com/articles/s41467-022-31854-8) has individual airway spheroid prior art but its public Source Data cannot join size, donor and treatment by track; the FIS_analysis demonstration repository (https://github.com/hmbotelho/FIS_analysis) has one plate and ambiguous track labels. A separate 2025 respiratory object study (https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1013589) uses forskolin rather than matched modulator/vehicle and truncates small objects. No newly verified public source simultaneously provides independent multiple CF intestinal donors, matched modulator/DMSO and zero-forskolin, baseline/end individual track IDs, and raw images/masks with plate/well provenance. This is a bounded search, not an assertion that no such data exist. No new cohort score or registered outcome test is justified yet.

## Segmentation source and comparator

Original OrgaSegment `Organoid Basic` Zenodo https://zenodo.org/records/10278229 identifies 20211206 train/val/eval human intestinal brightfield masks, CC BY 4.0. The same release already supplied our original 231 images, including all original test filenames; their filenames alone cannot prove donor/field independence. Its publication software release https://github.com/Living-Technologies/OrgaSegment/releases/tag/v1.0.1 identifies author model `OrganoidBasic20211215.h5` (255,833,056 bytes), and the exact release asset URL https://github.com/Living-Technologies/OrgaSegment/releases/download/v1.0.1/OrganoidBasic20211215.h5 responded to a byte-range request. The tagged source includes `lib/metrics.py` and `predict_mrcnn.py` (https://github.com/Living-Technologies/OrgaSegment/tree/v1.0.1). This repairs the **weights-location question only**. It does not establish a runnable environment or an independent acquisition-disjoint masked test set, and old 12 plus moved two images cannot serve as a sealed benchmark. Do not promote the rounded paper mean 0.76 into a paired model comparison.

Next: find a third-party labeled human organoid release with donor/acquisition metadata and masks; establish disjointness to all model-training/selection sources. Then pin both checkpoints, dependency versions, original scorer and paired group-level uncertainty before any target mask is opened. If provenance or a working comparator remains absent, report this specific blocker rather than infer superiority.

## Adjacent May 2026 image release and comparator runtime

The newly surfaced iOrganoAssay Zenodo record https://zenodo.org/records/20351867 (DOI 10.5281/zenodo.20351867; published 23 May 2026, CC0) contains a 1,817,410,571-byte ZIP advertised as daily brightfield images, segmentations, morphometric metrics, high-resolution images and metadata, plus Ctrl-versus-DSS validation. A subsequent check of its own software README https://github.com/swnam153/iOrganoAssay establishes these are **mouse intestinal organoids**, with 234 brightfield images and Ctrl/DSS treatment. The README links https://zenodo.org/records/18627306 ; its live record has the same title, creator, date and ZIP size, so the two record IDs do not constitute independent acquisitions. The README calls the validation images ground truth but our byte-range screen did not independently verify manual labeling or pixel-level instance semantics. A range read of its ZIP directory (no full download or mask inspection) listed 1,264 archive entries including 28 `6.Validation/*_GT.jpg` ground-truth filenames, 14 Ctrl and 14 DSS, paired with `*_BF.jpg` and `*_Seg.jpg`. A range-read of the 13,597-byte `0.metadata.xlsx` found only a one-cell `filename` header in its first sheet, not donor/plate/acquisition IDs. The source fails the proposed human CF intestinal eligibility at tissue/species and intervention: mouse DSS is not a human CFTR modulator FIS or a patient/donor-disjoint human segmentation test. Ctrl/DSS groups are treatment labels, not independent patients. No AP was computed. An alternate-domain benchmark would require a new purpose-specific preregistration, and could not be described as a repaired human benchmark win.

For the author comparator, v1.0.1 `conf/environment.yml` pins Python 3.6.13, tensorflow-gpu 1.15.0, keras 2.2.5, and an upstream `Living-Technologies/Mask_RCNN` v2.1.4 fork; `eval_mrcnn.py` invokes the `OrganoidBasic20211215.h5` weights and `lib/metrics.py` average-precision routine. Exact source https://github.com/Living-Technologies/OrgaSegment/tree/v1.0.1 . This workspace presently has Python 3.10.12, no TensorFlow/keras/MRCNN and no GPU command, so the old inference environment was not executed. A modern port would require parity tests before a paired AP claim; a weight-file HTTP byte-range response is not an executed author comparator.

## Two further image-source triages (28 September, 11:44 IST)

The independent human colorectal-cancer-organoid annotation tool at https://github.com/HelmholtzAI-Consultants-Munich/Colorectal-Cancer-Organoids-Detection describes local input `images/` and separately stored bounding-box annotations, with a code path to make masks. Its public tree exposes code and notebook assets, not a demonstrated raw image-plus-instance-GT cohort carrying donor/plate/acquisition metadata. A tool capable of exporting masks is not a public source of new hand-labeled test images. It also concerns colorectal cancer rather than CF intestinal swelling. No mask or AP score was opened.

The 2025 PLOS ONE human intestinal-organoid imaging study https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0332418 says in its own Data Availability section that relevant data are within article/supporting files. Its described pipeline uses CellProfiler fluorescence-pixel quantification of entire cropped wells, not a released, documented multi-donor brightfield instance-mask acquisition cohort or paired CFTR FIS tracks. It is methodological adjacent work, not an eligible human CF benchmark or phenotype validation from article text alone.
