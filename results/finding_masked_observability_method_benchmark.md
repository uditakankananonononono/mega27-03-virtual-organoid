# A frozen synthetic-mask comparison did not meet its method-improvement criterion

28 September 2026. The protocol `notes/prereg_masked_observability_method_benchmark_20260928.md` was pushed first at `e534528`, before synthetic missingness outcomes. This test holds the already observed 4,964 positive-A0/A1 source tracks as known truth in the original 31 blocks and 12 donors; it never observes the real source's missing endpoints or never-detected baseline objects. `scripts/benchmark_masked_observability.py` checks the pinned source SHA256 and writes all 300 mask-level results to `results/masked_observability_method_benchmark.json`. Under synthetic masks, the equal-donor mean of donor-median large-minus-small drug-versus-DMSO contrast in the full positive-pair frame is +0.207978 log units. That is the simulation truth, NOT the full baseline-detected population effect.

The lock required cell-range containment >=90% **and** median cell/global width <=0.90 in each mechanism. It **FAILED** the width criterion in all three. The apparent 100% containment of the *aggregate* truth under these broad scenarios does not give a 95% confidence interval for an individual hidden outcome: more than 10% of hidden individual responses were outside the cell-specific 5th-95th observed range in each mechanism. These intervals span zero in every one of the 300 runs, so they identify no sign even in this positive-pair simulation. The IPW reference knows the simulator's baseline propensity under MCAR/MAR; it is deliberately misspecified under MNAR, and is not a deployable real-data correction. With the masked truth already restricted to positive paired objects, this exercise does not refute or establish the biological size effect in the source population. Original sign 9/12 and zero-forskolin specificity 3/11 remain FAIL; independent segmentation win remains withdrawn. Generic missing-outcome sensitivity analysis predates this project (e.g. https://pmc.ncbi.nlm.nih.gov/articles/PMC10524136/), and this failed finite test supplies no grounds to claim a novel superior algorithm.

Protocol deviation note: the preregistration said rejected cell masks would use a separately seeded generator. The implementation uses the same seed-initialized NumPy generator for redraws; no cell exceeded the 100-redraw limit and no whole replicate became ineligible, but exact masked objects may differ from that specified stream. This does not change the first-stage mask model or fixed 300-run metric calculation; replay uses the implementation and source hashes.
