# Pre-registration: InterPro domain coverage among liver versus brain deficits

Registered before InterPro queries. Official API https://interpro-documentation.readthedocs.io/en/latest/api.html . This is an exploratory annotation audit of the fixed top-100 deficit genes per organ (results/strict_organ_deficits.csv). A tractable fixed target set of six previously named liver drug-metabolism deficits (CYP2D6, CYP2C9, CYP2C19, UGT1A1, SLCO1B1, VKORC1) and six previously named brain deficits (OPALIN, MAG, C1QB, HBB, HBA2, S100A9) will be mapped via reviewed human UniProt IDs and queried to InterPro for domain entries. H1: at least four of six liver targets map to a biochemical catalytic/transport domain family distinct from the six brain targets. This is a qualitative annotation test, not a statistical mechanism test; classify domains only from InterPro names, never invent. A target without one-to-one reviewed protein mapping is unresolved. Report exact accession/domain IDs and raw evidence. Given post hoc targets, no discovery claim whatever the outcome.
