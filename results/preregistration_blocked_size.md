# Pre-registration: matched-block stress test of size attenuation

The earlier date-split test pools experiments and forskolin concentrations within donor. Here lock the same 17-donor OrgaSegment DIS accession, previously chosen small A0 <722 and large A0 >=1400 px thresholds, Trikafta versus DMSO, positive forskolin only, before computing this contrast. Within each donor x experiment x forskolin concentration block, require >=3 organoids in each of four treatment/size cells and compute (drug-large - DMSO-large) - (drug-small - DMSO-small) on mean log swelling. Aggregate blocks by the median within donor to avoid treating plate units as independent people. H1: >=8 eligible donors, majority with positive median block effect and exact one-sided donor sign-test p<0.05. Also report number of eligible blocks per donor, pooled block median, and count of donors excluded. If fewer than 8, label uninterpretable; if not significant, fail. This SAME-accession stress test reduces dose/experiment confounding but not selection leakage (size thresholds were selected using this accession), image segmentation bias, missing phenotype mechanisms, or lack of independent patients.
