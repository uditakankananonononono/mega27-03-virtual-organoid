# Pre-registration: independent image-analysis pipeline sensitivity on the same FIS demo plate

The existing external FIS result used CellProfiler tracked-object CSVs on hmbotelho/FIS_image_analysis's one intestinal-organoid demo plate. The same repository provides Fiji/ImageJ `objects.csv` for the same 32 chosen wells and conditions, a distinct segmentation/tracking pipeline but NOT a new biological dataset. A sample header was inspected before preregistration and has `TrackObjects_Label`, `Metadata_timeNum`, and `Math_area_micronsq`. Before downloading the full Fiji outputs, lock selection of all 16 vehicle and all 16 VX-809/VX-770 combo wells with eight dose levels and two wells/condition/dose; matching is by well/time/object track ID, not CellProfiler labels.

Compute paired time-0/time-6 log area ratio for unique track/time rows with positive finite area, using Fiji's own global pooled 25th/75th baseline-area quantiles as small/large (not the CellProfiler numerical cutoffs). At each dose require >=5 tracks per cell and both wells per condition, then take the combo-minus-vehicle large-minus-small effect across tracked objects as in the CellProfiler primary test. H1 is positive median across >=4 eligible dose strata and at least six of eight dose effects positive. Do not use a p-value over correlated doses as a donor-level inference. Separately compute equal-well contrasts and the four-condition size-bin retention fractions to see whether the CellProfiler attrition issue persists; these are descriptive, with no pass gate. If H1 fails, report pipeline sensitivity as negative. If it passes, say technical pipeline robustness only. There is still one donor, one plate, same images, and no independent-patient evidence.
